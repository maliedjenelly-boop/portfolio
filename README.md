## Stack & parti pris

- HTML5 · CSS3 · JavaScript vanilla (zéro dépendance)
- Typographie : Space Grotesk · Inter · JetBrains Mono
- Palette sobre : near-black / off-white / gris + un accent électrique unique
- Micro-interactions : scroll-reveal, spotlight sur cartes, boutons magnétiques,
  cursor glow, marquee, scroll-spy, barre de progression
- Accessibilité : respect de `prefers-reduced-motion`, responsive mobile complet
- Hébergé sur GitHub Pages
